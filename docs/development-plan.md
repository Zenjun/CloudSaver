# 개발 계획 및 결정 대기 항목

상태: Phase 0 설계, Phase 1 데모 CLI, Phase 2 AWS 수집기, Phase 3 탐지 정책, Phase 4 로컬 비용·설명 명령 구현. 실제 AWS 계정 조회는 미검증이다. 원본 계획은 [`agent.md`](../agent.md)다.

## 현재 저장소와 충돌

2026-10-19 확인 결과, 저장소에는 `agent.md`와 제목만 있는 `README.md`가 있었고 작업 트리는 깨끗했다. 기존 코드·테스트·라이선스·패키지 설정은 없었다. 설계와 충돌하는 구현은 발견되지 않았다. 현재 환경은 Linux aarch64 / Python 3.13.5이며 Raspberry Pi 커널로 보인다. 이것만으로 친구 소유 장비 여부나 다른 OS의 호환성을 확정하지 않는다.

MVP는 Phase 1–4와 실제 기능에 맞는 설치·보안 문서까지다. Demo Mode는 Phase 1의 핵심이고, 비용 추정은 금액을 만들어내지 않는 것이 완료 조건이다.

## Phase 1 작업 순서

1. 지원 Python 버전과 최소 의존성 후보를 공식 배포 정보로 확인하고 `pyproject.toml` 및 `src/` 패키지 구조를 만든다.
2. AWS를 전혀 import/초기화하지 않는 Demo 진입점과 정규화 모델을 만든다.
3. 개발 EC2, 보호된 프로덕션 EC2, 분리 EBS, 미사용 Elastic IP, 메트릭 부족 사례를 포함한 익명 fixture를 만든다.
4. 실제 규칙을 공유하는 간단한 분석, 표/JSON 렌더링, `DEMO DATA`, 명시적 출력 파일을 구현한다.
5. 자격 증명 없는 환경과 네트워크 차단 환경, JSON 스키마·결정성·종료 코드·비밀 노출을 테스트한다. 린트와 타입 검사를 실행한다.
6. 검증된 로컬 설치/실행 명령과 지원 환경을 README에 기록한다.

Phase 1에서는 실제 AWS API 호출, 클라우드 쓰기, Docker 상시 실행, Git push를 하지 않는다.

## Phase 1 검증 기록

2026-10-19 현재 Linux aarch64 / Python 3.13.5에서 데모 CLI, JSON 출력, 네트워크 차단 및 무자격 환경, 출력 파일 권한·덮어쓰기 거부, 도움말·잘못된 인수 종료 코드를 확인했다. `pytest`, Ruff, mypy를 실행했고, sdist/휠을 빌드해 새 가상환경에서 휠 설치 후 데모 실행을 검증했다. 다른 Python 버전과 OS에서는 아직 실행하지 않았다. AWS API를 호출하지 않았다.

## Phase 2 검증 기록

EC2/EBS 페이지네이션, Elastic IP, CloudWatch 결과 페이지네이션, 메트릭 결측과 권한 오류, 스로틀링, 중간 페이지 실패, 지역 검증, 제한된 표준 재시도 설정을 botocore Stubber와 가짜 세션으로 시험했다. 수집 실패 범위를 보고서에 별도로 표시하고, 비용 절감 후보 분석은 `NOT_EVALUATED`로 표시한다. 테스트는 실제 AWS 계정에 접근하지 않았다. 실제 계정에서의 API·IAM·비용 검증은 별도 허락 후 진행한다.

## Phase 3 검증 기록

데모와 AWS 수집 결과가 공유 정책 엔진을 사용한다. EBS 분리, EC2 저사용률 의심, 미연결 Elastic IP의 세 정책을 구현했다. CPU 임계값, 14일 관찰 구간, 최소 샘플 수, 보호·보존 태그, 결측·오류 메트릭, 부분 수집 상태를 로컬 fixture로 시험했다. 가격 자료가 없어 절감액은 `UNKNOWN`이다. 실제 AWS 조회는 하지 않았다. 상세 기준은 [탐지 정책](policies.md)에 있다.

## Phase 4 검증 기록

저장된 JSON 보고서의 `report`, `explain`, `opportunities` 명령과, 사용자가 제공한 월별 비용 항목의 조건부 계산 엔진을 구현했다. 데이터가 없으면 절감액은 `UNKNOWN`이다. EC2 시나리오는 EBS·IPv4 잔존 비용을 변경 후 비용에 남긴다. 보호 태그, ASG 소속, 중요도 태그, 결측 관찰 자료의 위험 근거를 확대했다. 계산식·입력·제외 비용은 [비용 계산 문서](cost-model.md)에 있다. 실제 AWS 가격·청구 조회와 계정 검증은 하지 않았다.

- 공개 배포 시 라이선스 선택과 저작권 표기. 지금은 결정하지 않는다.
- Phase 2의 실제 AWS 읽기 조회를 시험할 계정/리전과 호출 비용 허용 범위. 지금은 필요하지 않다.
